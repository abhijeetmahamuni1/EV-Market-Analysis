# 🚗 EV Market Analysis — Data Cleaning & Visualization

## 📌 Project Overview

This project focuses on analyzing Electric Vehicle (EV) market data using Python.

The dataset is intentionally unclean and contains real-world data quality issues such as missing values, duplicate records, inconsistent text values, mixed date formats, invalid values, and outliers.

The goal of this project is to practice the complete Data Analyst workflow:

Raw Data → Data Understanding → Data Cleaning → EDA → Data Visualization → Business Insights

## 🛠️ Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## 🧹 Data Cleaning

The project includes:

- Identifying and removing duplicate records
- Handling missing values
- Standardizing manufacturer names
- Cleaning city and state names
- Converting data types
- Handling invalid values
- Identifying and treating outliers
- Cleaning date formats

## 📊 Analysis

The project will analyze:

- EV registrations over time
- Manufacturer performance
- EV model popularity
- State-wise EV adoption
- Vehicle category performance
- Price analysis
- Battery range analysis
- Units sold
- Charging type
- Urban vs semi-urban vs rural adoption

## 🎯 Business Objective

The objective is to understand EV market trends and identify patterns in manufacturers, vehicle categories, locations, pricing, battery range, and sales.

## 🚧 Project Status

**Work in Progress 🚧**
